## b) Salasanan obfuskointi

Tässä tehtävässä tarkoituksena oli piilottaa salasana siten, ettei se näkyisi strings-komennon tulosteessa selväkielisenä. Aluksi yritin piilottaa salasanan ASCII-arvoista muodostetun taulukon avulla, jotta strings ei löytäisi salasanaa suoraan merkkijonona binääristä:

<details>
<summary>Näytä koodi</summary>

 ```bash
#include <stdio.h>
#include <string.h>

int main() {
    char password[20];

    char correct[] = {
        115,97,108,97,45,
        104,97,107,107,101,114,105,45,
        51,50,49,0
    };

    printf("What's the password?\n");
    scanf("%19s", password);

    if (strcmp(password, correct) == 0) {
        printf("Yes! That's the password. FLAG{Tero-d75ee66af0a68663f15539ec0f46e3b1}\n");
    } else {
        printf("Sorry, no bonus.\n");
    }

    return 0;
}
```
</details>

Tämä ei kuitenkaan toiminut sillä tavalla kuin odotin, sillä strings löysi edelleen osia salasanasta binääristä. Salasana ei näy kokonaisena, kuten ennen, mutta käytännössä se on edelleen helppo päätellä:

Tällä kertaa oli pakko hyödyntää hieman tekoälyä (Copilot). Kinasteltuamme hetken sopivimmasta obfuskointimenetelmästä päädyimme käyttämään XOR-operaatiota (exclusive OR). XOR-obfuskoinnissa salasana tallennetaan binääriin muunnetussa muodossa, jolloin se ei näy suoraan strings-komennon tulosteessa. Ohjelma palauttaa salasanan alkuperäiseen muotoonsa vasta suorituksen aikana ennen vertailua. 

<details>
<summary>Näytä koodi</summary>

 ```bash
#include <stdio.h>
#include <string.h>

int main() {
    char password[20];

    char correct[] = {
        's'^42, 'a'^42, 'l'^42, 'a'^42,
        '-'^42,
        'h'^42, 'a'^42, 'k'^42, 'k'^42,
        'e'^42, 'r'^42, 'i'^42,
        '-'^42,
        '3'^42, '2'^42, '1'^42,
        0
    };

    for (int i = 0; correct[i] != 0; i++) {
        correct[i] ^= 42;
    }

    printf("What's the password?\n");
    scanf("%19s", password);

    if (strcmp(password, correct) == 0) {
        printf("Yes! That's the password. FLAG{Tero-d75ee66af0a68663f15539ec0f46e3b1}\n");
    } else {
        printf("Sorry, no bonus.\n");
    }

    return 0;
}
```
</details>

Kun ohjelma oli tallennettu, salasana ei enää näkynyt strings-komennon tulosteessa selväkielisenä. Suoritin vielä passtr-ohjelman syöttämällä siihen oikean salasanan testatakseni, ettei tehdyt muutokset rikkoneet mitään. Ohjelma hyväksyi salasanan ja toimi normaalisti:
